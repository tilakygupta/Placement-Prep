# PrepDesk – CS & Aptitude Practice Hub

## 🚀 Overview

**PrepDesk** is a lightweight and interactive study platform designed for students preparing for placements, technical interviews, aptitude tests, and competitive examinations.

The platform contains **400+ questions across 11 Computer Science and Aptitude subjects**, with detailed explanations, theory, and solutions. Built entirely using **HTML, CSS, and JavaScript**, it runs directly in the browser without requiring any backend or external dependencies.
